# **Multi-Dimensional Seismic Wavefields Reconstruction: A Compressed Sensing Approach with DCT Discrete Basis Sampling Dictionary**

## 1. Introduction
We proposed a novel algorithm that directly constructs the sensing matrix by arranging samples of Discrete Cosine Transform (DCT) basis functions. This method not only preserves the data sparsity but also allows for the discarding of some high-frequency components and significantly reduces computational load. This method can be adapted for data not located on grid points using bilinear interpolation, and it can also be applied to other measurements beyond point sampling and transforms beyond DCT.

**Key Features:**
* **Data Continuity:** Introduce a new algorithm using Discrete Cosine Transform to directly build a sensing matrix, preserving 3D data sparsity.
* **High Efficiency:** GPU-accelerated recovery algorithms utilizing PyTorch, which significantly reduces computational load and works with irregular data and other forms of measurements and transforms. 
* **Scalability:** Worked well on both synthetic and real seismic recordings, demonstrating applicability in earthquake response and imaging.

## 3. Data Download and Description
(1) **Synthetic Data**: We used the Direct Solution Method synthesized seismogram computation program, developed by Otsuru et al (2024), to calculate synthesized seismograms generated by a point source in a spherically symmetric, transversely isotropic medium.

We divided a 126 km×126 km area into a regular grid of 64×64 points. A triangular source-time function was selected, with the half-rise time varying randomly. The source mechanisms were also randomized, and the source locations varied from 10km to 300km near the center of the region. Using the PREM model (Dziewonsky & Anderson, 1981) as the velocity model, we generated 100 seismic events with a maximum frequency of 1 Hz. The synthesized seismograms at these regular grid points were computed, filtered with a bandpass of 10~100 seconds, and then sampled at 2-second equal intervals. The sampling was performed around the S-wave arrival time at the central grid point, resulting in 64 time-samples. This process finally formed a 64×64×64 data matrix, which serves as the wavefield to be reconstructed.

***Data format***: a $T \times H \times W \times C$ npy file, where T is time step, H and W are grid height and width, C is channel number (three components)



(2) **Real Data**: We selected seismic network data from stations near Los Angeles in Southern California following the Mw-7.0 Northern California earthquake on December 5, 2024 as an exsample, obtained from IRIS (https://ds.iris.edu). 

***Data format***: Station recordings is stored in a $N \times T$ data file of ".npy" format, where N is station numbers, T is time steps, and position of stations is stored in a $N \times 2$ data file of ".npy" format. 

Synthetic and real event data can be found at release "v1.0.0 - Seismic Data (Raw & Synthetic)"

## 5. Quick Start
(1) Before running, ensure the environment is ready.

(2) The data files "all_sta_data.npy", "sta_info.txt", "sta_pos_in_grid.npy", "test_sta_info.txt" are ready for a quick start.

(3) After downloading the "3DCS" dictionary, "CS3D_main.py" is the main progress, just run it. Other python scipts are all auxiliary functions.

(4) "GMT_plot.sh" is a plot script using bash shell, you may need GMT to run it.
